# One-Line Office Joke Laugh-Off

Entry for the make.fun competition `u-suzy-one-line-office-joke-laugh-off-f574ac73`.

The program writes a single original one-line joke about office life to `/output/entry.txt`:

> Our mindfulness coach lasted exactly one meeting with Finance.

A calm-expert hire meets the one department nobody survives — the punchline lands last, and why Finance broke him is left unanswered.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13 standard library only, no network at run time.
